¿Cómo funciona Twilio SMS API?

1. Registrar cuenta Twilio → obtener Account SID y Auth Token
2. Adquirir número de teléfono virtual
3. Hacer petición HTTP POST con credenciales Basic Auth
4. El API retorna un SID único por mensaje enviado
5. Twilio entrega el SMS al operador de destino

🔔 Web Push Notification — API del navegador

¿Cómo funciona Web Push API?

1. Solicitar permiso al usuario con Notification.requestPermission()
2. Si acepta → crear la notificación con new Notification(titulo, opciones)
3. Para push real en segundo plano → necesita Service Worker + servidor VAPID
4. El navegador muestra la notificación como alerta nativa del sistema

// BACKEND (Node.js + Express) — Enviar SMS con Twilio
const twilio = require('twilio');

const client = twilio(
  process.env.TWILIO_ACCOUNT_SID,   // Tu Account SID
  process.env.TWILIO_AUTH_TOKEN     // Tu Auth Token
);

app.post('/api/send-sms', async (req, res) => {
  const { to, body } = req.body;
  try {
    const message = await client.messages.create({
      body:  body,
      from: '+15120000000',   // Tu número Twilio
      to:    to
    });
    res.json({
      success: true,
      sid:     message.sid,
      status:  message.status  // "queued" → "sent" → "delivered"
    });
  } catch (error) {
    res.status(500).json({ success: false, error: error.message });
  }
});

// FRONTEND — Llamar al backend
async function enviarSMS() {
  const response = await fetch('/api/send-sms', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      to:   document.getElementById('smsDest').value,
      body: document.getElementById('smsMsg').value
    })
  });
  const data = await response.json();
  console.log('SID del mensaje:', data.sid);
}
